# 노드 경험 계약

## 범위·근거

- 사용자: ComfyUI 워크플로 작성자 · 원격 서버·모델·프로필 선택, 생성·전송 상태 확인
- 근거: 텍스트 최소화 요청 · [선택 UI](../../web/remote_choices.js) · [프로필 UI](../../web/remote_profiles.js) · [전송 UI](../../web/vae_delivery.js)
- 유지: 노드 ID·입출력·직렬화 위젯 순서·실행 정책 · 사용자 제목·선택·편집 초안
- 검증 경계: 코드·DOM 계약·실제 개발 UI 관찰 · 사용자 조사·접근성 적합성 인증 제외

## 작업·상태

| 작업 | 기본 표시·행동 | 실패·중단·재진입 | 완료 증거 |
| --- | --- | --- | --- |
| 서버·모델 선택 | 서버·현재 선택·짧은 조회 버튼 | 선택 보존·재조회 · 서버 변경 이전 응답 무효 | 현재 서버의 검증된 선택 목록 |
| 프로필 선택·편집 | 선택·관리 · 설명·모델 세부는 상세 | 초안 보존 · 저장 성공 후 목록 실패는 재저장 대신 재조회 | 저장 응답·선택한 프로필의 확인된 목록 |
| 프로필 삭제 | 대상 ID·inline 확인 | 취소 시 원래 선택·초안 유지 · 중복 요청 차단 | 삭제 응답 · 목록 반영 실패 별도 표시 |
| 공유 연결 확인 | 연결 상태·확인 행동 | 서버 변경 시 이전 상태 무효 · 오류 상세·다시 확인 | 현재 서버·공유 경로 확인 응답 |
| 생성·전송 관측 | 실제 단계·작업 구분 | 복귀 대기를 디코딩 성공으로 해석 금지 · 닫기 후 요청·타이머 정리 | 수신 이벤트·미리보기·최종 미디어 각각 구분 |

## 표시·조작

- 기본: 역할이 구분되는 노드 제목·필수 선택·현재 상태·다음 행동
- 상세: 설명·고급 설정·진단·이력 · 키보드·터치로 접근 가능한 펼침
- 오류: 짧은 상태와 복구 행동 · 긴 원문·기술 정보는 상세 · 성공·삭제·정리 미확인 상태 유지
- 조회: 비어 있지 않은 명시 선택의 자동 대체 금지 · 미지원 선택의 가시적 안내 · 실행 전 peer 검증 유지
- 좁은 폭·확대·긴 모델명: 내용 줄바꿈·작업 영역 스크롤 · 주요 조작 잘림 금지
- 비동기: 마지막 현재 서버 요청만 반영 · 현재 초안/선택 보존 · 닫기 후 UI 갱신 금지
- 동작 중: 중복 실행 차단 · 상태와 완료 증거 분리 · 프로필 재조회가 생성 요청을 실행하지 않는 계약
